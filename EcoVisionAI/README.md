# EcoVision AI — Smart Waste Classification

A beginner-friendly college mini project that classifies waste images with a **genuinely trained MobileNetV2 model**, stores successful predictions in SQLite, and presents disposal guidance in a responsive Flask web app.

> The application never fabricates a prediction. Until a model is trained, the Analyse button returns a clear setup message.

## Setup

```bash
cd EcoVisionAI
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Dataset setup and terms

Use the public **TrashNet** dataset: <https://github.com/garythung/trashnet>. It contains six classes in the original project: cardboard, glass, metal, paper, plastic, and trash. Review the dataset repository's current license and attribution terms before redistribution. Do not add a category that is not represented by the folders you train on.

Place class folders at `data/trashnet/<class-name>/image.jpg`. The training script discovers the actual folder names, sorts them, and stores them in `models/labels.json`.

```bash
mkdir -p data
# Download the dataset from its source, then extract/copy its class folders here.
# Example final path: data/trashnet/cardboard/cardboard1.jpg
```

## Train and evaluate

```bash
python train.py --data data/trashnet --epochs 10
```

The script uses a deterministic, stratified 70/10/20 split, so one image belongs to only one split. It saves:

- `models/ecovision_mobilenetv2.keras`
- `models/labels.json`
- `reports/metrics.json` with test accuracy and per-class precision/recall/F1
- `reports/confusion_matrix.png`

The confidence shown in the UI is the model's softmax score, **an estimate rather than a guarantee**. Scores below 0.55 are shown as Uncertain.

## Run the website

```bash
python app.py
# open http://127.0.0.1:5000
```

API endpoints: `GET /api/health`, `POST /api/predict` with multipart field `image`, `GET /api/history`, and `GET /api/dashboard`.

## Test

```bash
python -m unittest api_test.py -v
```

The tests cover health, missing files, invalid extensions, and the required missing-model behavior. A real prediction test should be added after training if you have a labelled fixture image.

## Faculty demonstration

1. Show the dataset class folders and the command used for training.
2. Open **About Project** to explain preprocessing, transfer learning, and the confidence threshold.
3. Upload a clear recyclable item image and show the prediction plus disposal advice.
4. Open Dashboard and History to show records that were actually generated by the model.
5. Stop or rename the model file and demonstrate that the app refuses to pretend it can classify.
6. Explain that local recycling rules vary and the advice is general guidance.
