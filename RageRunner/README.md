# RAGE RUNNER

A fully playable, original stylized 3D endless survival shooter prototype for Unity 2022.3 LTS+. It uses procedural primitives and runtime UI so it has no external asset dependencies.

## Run
1. Open `RageRunner/` in Unity 2022.3 LTS or newer.
2. Open `Assets/_Game/Scenes/RageRunner.unity`.
3. Press Play. Use **A/D** or **Arrow keys** to strafe; on Android drag left/right. Press **Space** for the nuclear ability.

## Included
- Auto-forward third-person arena movement and automatic weapons.
- Six modular weapon definitions, projectile variants, splash damage, upgrades and rage mode.
- Eight enemy archetypes with scalable wave difficulty, mini-bosses and phase-changing major bosses.
- Coins, PlayerPrefs persistence, wave rewards, upgrade cards, menu, HUD, game over and restart loop.
- Procedural arena, lighting, primitives, screen-space UI and Android landscape settings.

The project intentionally avoids copyrighted characters, models, branding and ripped assets. Replace the procedural materials, meshes, audio hooks and VFX with production assets under `Assets/_Game/` without changing the gameplay contracts.
